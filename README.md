To-Do (Mini Social Media App)

Mini social media app with like, delete, update, unlike functions.
A full-stack task-based application built with **EJS, Node.js, Express, MongoDB, and authentication (login & logout). Users can add tasks, update them, delete them, and like/unlike posts.

🚀 Features

✔️ User authentication (Login & Logout)  
✔️ Create, Read, Update, Delete (CRUD) tasks  
✔️ Like & Unlike tasks  
✔️ EJS templating for UI  
✔️ Persistent storage with MongoDB  
✔️ Responsive and user-friendly UI

## 🛠 Technology Stack

| Frontend | Backend | Database |
|----------|---------|----------|
| EJS | Node.js | MongoDB |
| HTML5 | Express.js | Mongoose |
| CSS | JavaScript (ES6) |
